# Globex Product Catalog

Freight Hub is the core platform for booking, tracking and invoicing shipments. It connects to more than 300 carriers through a single API and supports pallets, containers and parcels.

Route Planner is a depot-to-door optimizer. It builds driver routes from delivery addresses and time windows, and it recalculates when a vehicle is delayed.

Customs Desk handles declarations and duty estimates for 40 countries. It produces the commercial invoice and packing list used at the border.

Warehouse Sync is a lightweight connector for legacy warehouse management systems. It runs as an on-premise agent and sends stock levels to Freight Hub every five minutes.

Every product shares one account, one login and one billing record, so teams can move between modules without a new setup. Administrators control which modules each team can see from the central settings page.

Pricing for each product is listed in the pricing sheet, and the catalog team updates the product names and descriptions after each quarterly release.
